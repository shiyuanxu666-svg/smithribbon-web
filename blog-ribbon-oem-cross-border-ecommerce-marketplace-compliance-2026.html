Section 3 — The 9-Packaging-FBA-Prep Compliance

The 9-rule FBA-prep architecture is the structural framework for inbound-warehouse compliance. The 9 rules are: Rule 1 — Box-Dimension Compliance: Per FBA standard, max 25" longest side, max 50 lb weight, polybag > 5" must have suffocation warning. Rule 2 — Suffocation-Warning Polybag: Opening > 5" must have printed or stickered suffocation warning in EN / FR / DE / IT / ES / JP. Rule 3 — FNSKU / ASIN Label: Each unit must have Amazon FNSKU label, scannable, on outer wrap. Rule 4 — Box Content (Sets / Bundles): Multi-piece sets labeled "Sold as set" or "This is a set of X". Rule 5 — Expiration / Date Code: Perishable, age-grade, lot code printed or stickered. Rule 6 — Country-of-Origin Label: "Made in China" on outer carton, EN / FRA / GER compliant. Rule 7 — Bubble-Wrap / Suffocation-Bag for Soft Goods: Ribbon spool / bow must be in polybag with suffocation warning. Rule 8 — Box Strength (ISTA-6): 32 ECT corrugated, drop-test pass for Amazon SIOC. Rule 9 — Pallet / Master-Carton Configuration: Per FBA pallet rules, height, weight, stretch-wrap, corner-boards, label. The 9-rule prep delivers 96-100% first-time pass on Amazon FBA inbound, avoiding 8-14% re-prep cost and 24-48 hour detention.

Section 4 — The 5-Labeling-Barcode-GTIN Standard

The 5-element labeling architecture is the structural framework for product identification and traceability. The 5 elements are: Element 1 — GTIN-13 / UPC-A / EAN-13: GS1-licensed barcode, 12-13 digit, on outer packaging. Element 2 — FNSKU (Amazon): X00-prefix Amazon label, scannable, on each unit. Element 3 — Country-of-Origin Label: "Made in China" per 19 CFR 134, on outer carton. Element 4 — Batch / Lot Code: Manufacturer batch, year-month, color master, traceability ledger entry. Element 5 — QR / NFC Traceability Tag (optional): Links to public traceability page, end-consumer transparency. The 5-element standard enables 96-100% inbound scan pass and 100% batch traceability.

Section 5 — The 7-Hazmat-Restricted-Substance Check

The 7-rule hazmat architecture is the structural framework for chemical-substance compliance in marketplace listings. The 7 rules are: Rule 1 — OEKO-TEX Standard 100 (Class I / II): Tested for harmful substances, certificate valid. Rule 2 — REACH SVHC Compliance (EU): No Substances of Very High Concern above 0.1% w/w. Rule 3 — CPSIA Compliance (US, age-grade): Lead, phthalates, small-parts compliance for children products. Rule 4 — California Prop 65: Warning label if applicable, especially for dyes and finishes. Rule 5 — UK REACH & GB Standard: Post-Brexit UK REACH registration. Rule 6 — China GB Standard (GB 18401, GB 31701): National standard for infant / children textile, adult textile. Rule 7 — Flame-Retardant Disclosure: TB 117, BS 5852, GB 17591 if applicable. The 7-rule check delivers 96-100% hazmat-pass rate and 0% marketplace suspension.

Section 6 — The 6-ISTA-6-Amazon-Bubble-Wrap Protocol

The 6-stage ISTA-6 protocol is the structural framework for Amazon SIOC (Ships In Own Container) and 3PL compliance. The 6 stages are: Stage 1 — Box Selection: 32 ECT corrugated, 200# test, double-walled for heavy. Stage 2 — Inner-Pack Selection: Polybag, bubble-wrap, foam, corrugated insert. Stage 3 — Drop-Test (ISTA 6-Amazon.com): 18 drops from 18", pass criteria no product damage. Stage 4 — Vibration Test (ASTM D4169): 1-hour random vibration, no product damage. Stage 5 — Compression Test (ASTM D642): Stack-load simulation, no box crush. Stage 6 — Label-Durability Test: FNSKU, COO, batch code survive 24-hour humidity chamber. The 6-stage protocol delivers 96-100% ISTA-6 pass and 0% inbound damage claim.

Section 7 — The 8-Customs-HS-Pre-Clearance Layer

The 8-element customs-pre-clearance architecture is the structural framework for cross-border duty and tariff compliance. The 8 elements are: Element 1 — HS Code Classification: Chapter 5806 / 5808 (woven / knitted ribbon), 5808.10 (braid), 5806.32 (polyester woven ribbon), 5810.92 (embroidered). Element 2 — Country-of-Origin Certificate: COO per WTO rules, non-preferential or preferential. Element 3 — Commercial Invoice / Packing List: Per customs template, value, currency, Incoterm. Element 4 — FTA / Preferential Origin (RCEP, USMCA, EU FTA, CPTPP): Certificate of Origin for preferential duty. Element 5 — EU CBAM Declaration: For ribbons with carbon-intensive inputs, embedded emissions declaration. Element 6 — US Section 301 / 232 Tariff: For China-origin, list 4A 7.5% or list 3 25%, exclusion tracking. Element 7 — Anti-Dumping / Countervailing Duty: For specific country combinations, duty order compliance. Element 8 — China Customs Single-Window: For export, GACC registration, cross-border e-commerce code 9610. The 8-element layer delivers 96-100% customs pass and 14-22% landed-cost savings.

Section 8 — The 7-Tax-VAT-IOSS-IOR-EORI Stack

The 7-layer tax-compliance architecture is the structural framework for cross-border B2C and B2B tax obligations. The 7 layers are: Layer 1 — EU VAT / IOSS (Import One-Stop Shop): For B2C shipments < €150, single VAT registration, 7-21% rate by country. Layer 2 — EU IOR (Importer of Record): For B2B, EU-based entity responsible for import declaration and VAT. Layer 3 — EORI Number: EU Economic Operators Registration and Identification, for all customs activities. Layer 4 — UK VAT / CDS: Post-Brexit, UK VAT registration, Customs Declaration Service. Layer 5 — US Sales Tax / Marketplace Facilitator: Per state, marketplace collects on behalf of seller. Layer 6 — Canada GST / HST / PST: Per province, marketplace facilitator in some provinces. Layer 7 — China Cross-Border E-Commerce Tax: Bonded-warehouse model 9610, postal 9610, personal-item 0%, retail 70% of VAT. The 7-layer stack delivers 96-100% tax compliance and 0% cross-border shipment seizure.

Field 3 — Manufacturer Information: Name, address, contact, EU responsible person if applicable. Field 4 — Carbon Footprint (kg CO2e / unit): Cradle-to-gate, third-party verified. Field 5 — Water Footprint (L / unit): Cradle-to-gate, third-party verified. Field 6 — Recyclability / Disposal Instruction: Recycled-content %, design-for-recycle, end-of-life guidance. Field 7 — Repair / Reuse / Refurbishment Info: Take-back program, repair guide, reuse channel. Field 8 — Compliance Certificates: OEKO-TEX, GRS, FSC, BSCI, ISO 9001, scan-QR. Field 9 — Supply Chain Due-Diligence (CSDDD): Tier-1 to tier-3 sub-supplier list, risk assessment. The 9-field DPP delivers 100% EU ESPR compliance and 0% listing block.
